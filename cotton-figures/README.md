# Cotton figures

The numbered SVGs are the editable source figures, with JPG exports alongside
them for easy download. Regenerate the SVGs with:

```sh
python cotton-figures/generate_figures.py
```

Sources are linked in each figure. Figures 06 and 13 show study-specific
ranges, not cultivar-level measurements or universal biological limits.
Figure 07 shows fatty-acid ranges across three genotypes, not a single
composition that must sum to 100%. The original JPGs are archived under
`cotton-figures/originals/` and should not be used as current teaching material.
